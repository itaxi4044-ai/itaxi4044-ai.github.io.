# SAM[U}®AJ Digital Solutions website

A responsive single-page business website. No third-party scripts, cookies, analytics, or payment processing are included.

## Before publishing
1. Replace all `[ADD ...]` placeholders with accurate legal business information, contact email and address. Do not invent a registered business.
2. Verify the services listed are genuinely deliverable.
3. Add the legally appropriate privacy notice, terms, cancellation/refund information, and any mandatory business disclosures before taking payments.
4. Test on mobile and desktop.

## Publish for free with GitHub Pages
Create a GitHub repository, upload `index.html` to its root, and enable Settings > Pages > Deploy from a branch (`main`, `/root`). GitHub will show the live URL after deployment. The site is NOT published by this ZIP.

## Stripe
Only submit the real, live URL once the website is published and complete. Stripe may require additional business verification and policies. No Stripe integration is currently installed.
